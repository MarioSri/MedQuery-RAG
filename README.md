# 📖 Overview

MedQuery is a Retrieval-Augmented Generation (RAG) application designed to answer medical questions using a curated medical knowledge base.

Unlike a traditional chatbot, MedQuery first retrieves the most relevant medical information using semantic search and then provides an evidence-grounded response generated by an LLM.

The project consists of two completely independent applications:

* **Frontend** – Interactive dashboard for querying the system and managing documents.
* **Backend** – FastAPI-based RAG service responsible for retrieval, embeddings, vector search, and LLM inference.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/MedQuery.git
cd MedQuery
```

Install dependencies

```bash
cd backend

pip install -r requirements.txt
```

Create `.env`

```env
ANTHROPIC_API_KEY=YOUR_API_KEY
HOST=0.0.0.0
PORT=8000
CORS_ORIGINS=*
```

Run the backend

```bash
python main.py
```

Open

```text
medquery-dashboard.html
```

in your browser.

# 🚧 Current Limitations

* Uploaded documents are stored in memory only.
* Uploaded documents are lost when the backend restarts.
* Designed for a lightweight, single-instance deployment.
* No authentication or authorization.
